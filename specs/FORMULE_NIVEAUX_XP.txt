CALCUL DES NIVEAUX ET DE L'XP — URBINEMA
Version : 1.1
Date : 2026-09-18
Statut : formule V1 paramétrable, à ajuster après tests


========================================================================
0. DÉCISIONS PRODUIT
========================================================================

- Niveau initial : 1.
- XP initiale : 0.
- Niveau maximum : 50.
- Rang et niveau strictement indépendants.
- Sources d'XP :
    film vu (une fois) = 10 XP  (essai 0.2.1 ; était 40)
    quête Bronze = 100 XP
    quête Argent = 250 XP
    quête Or     = 500 XP
- Le niveau ne redescend jamais (sauf recalage si on change le tarif film
  déjà écrit dans le ledger).
- Une quête ne peut attribuer son XP qu'une fois.
- Un film n'attribue ses XP qu'une fois
  (`xp_transactions.source = FILM`, unicité par movieId).


========================================================================
1. INCOHÉRENCE DES REPÈRES INITIAUX
========================================================================

Les repères fournis étaient des intentions, pas une suite mathématiquement
compatible :

  niveau 45 ≈ 48 200 XP
  niveau 49 ≈ 97 000 XP
  niveau 50 ≈ 100 000 XP
  coût final ≈ 3 000 XP

Passer de 48 200 à 97 000 en quatre niveaux demanderait en moyenne
12 200 XP par niveau, puis le coût retomberait brutalement à 3 000.
Ce mur n'est ni progressif ni cohérent avec l'objectif d'un coût mensuel
qui finit par se stabiliser.

ARBITRAGE V1 :

- conserver précisément les repères des niveaux 1 à 20 ;
- faire converger le coût vers un plateau ;
- conserver niveau 49 ≈ 97 000 ;
- atteindre exactement 100 000 au niveau 50 ;
- accepter que les anciens repères 25 à 45 soient relevés.


========================================================================
2. DÉFINITIONS
========================================================================

L       = niveau courant, 1 <= L <= 50
T(L)    = XP cumulée minimale pour atteindre le niveau L
C(L)    = XP requise pour passer du niveau L au niveau L + 1

C(L) = T(L + 1) - T(L)

Le niveau correspondant à une XP cumulée X est :

Niveau(X) = max { L dans [1, 50] tel que T(L) <= X }

À partir du niveau 50 :

Niveau(X) = 50, quelle que soit la valeur de X.


========================================================================
3. COÛT DU NIVEAU SUIVANT
========================================================================

Les quatre premiers coûts reprennent les repères éditoriaux :

C(1) = 115
C(2) = 140
C(3) = 200
C(4) = 270

Puis :

C(L) = 275 + 20 * (L - 5)          pour 5 <= L <= 9

C(L) = 520 + 40 * (L - 10)         pour 10 <= L <= 14

C(L) = 700 + 40 * (L - 15)         pour 15 <= L <= 19

C(L) = 1100 + 525 * (L - 20)       pour 20 <= L <= 24

C(L) = 3202                         pour 25 <= L <= 49


LECTURE PRODUIT
------------------------------------------------------------------------

- Niveaux 1 à 5 : une quête Argent ou Or peut suffire.
- Niveaux 10 à 20 : une à quatre quêtes selon leur difficulté.
- Niveaux 20 à 25 : transition volontaire vers le rythme long.
- Niveaux 25 à 50 : coût fixe de 3 202 XP.

Au plateau, il faut environ :

  33 quêtes Bronze ;
  13 quêtes Argent ;
   7 quêtes Or.

Avec trois quêtes par semaine, le rythme dépend du mélange Bronze /
Argent / Or et reste à l'échelle de plusieurs semaines ou mois.

Le maximum hebdomadaire V1 est 850 XP. Au plateau, un niveau demande donc
au minimum 3,77 semaines si les trois quêtes sont terminées : l'objectif
« environ un niveau par mois » est respecté. Atteindre 100 000 XP demande
au minimum environ 118 semaines, soit un peu plus de deux ans.

========================================================================
5. PARAMÉTRAGE DANS LE CODE
========================================================================

La V1 implémente une table de seuils générée par une configuration unique :

  MAX_LEVEL             = 50
  BRONZE_XP             = 100
  SILVER_XP             = 250
  GOLD_XP               = 500
  PLATEAU_START_LEVEL   = 25
  PLATEAU_LEVEL_COST_XP = 3202

Les segments précédents sont regroupés dans une liste typée :

  XpCurveSegment(
      startLevel,
      endLevel,
      baseCost,
      incrementPerLevel
  )

La table T(1)..T(50) est construite une fois, validée au démarrage du
moteur métier et testée en JUnit.

INVARIANTS À TESTER
------------------------------------------------------------------------

- T(1) = 0.
- T(50) = 100 000.
- T(L + 1) > T(L) pour tout L < 50.
- C(L) > 0 pour tout L < 50.
- Niveau(T(L)) = L.
- Niveau(T(L + 1) - 1) = L.
- Niveau(X) = 50 pour X >= 100 000.
- Les récompenses Bronze / Argent / Or sont strictement croissantes.


========================================================================
6. AJUSTEMENTS FUTURS
========================================================================

Cette courbe est une configuration produit, pas une vérité mathématique.
Elle sera ajustée après observation du rythme réel des quêtes.

Modifier la courbe ne doit pas retirer un niveau déjà atteint :

  niveauAffiche =
      max(niveauCalculeDepuisXp, niveauMaximumHistorique)

Le niveau maximum historique est donc persisté comme un cliquet, exactement
comme le rang maximum historique.
